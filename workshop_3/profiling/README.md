# Silver profiling reports

Generated by `notebooks/03_silver_quality_review.ipynb` using the instructor's
`ProfileReport` workflow and saved source data. Open the HTML files in a browser;
the notebook also includes links. No weather API is called.

- `ghcn_station_quality.html`: 1,826 station dates, PRCP/TMAX/TMIN and the actual
  date. The reported 1,436 PRCP zeros and unique daily dates are real source
  properties, not automatically data errors.
- `silver_source_quality.html`: a seven-column source/time/point/magnitude-
  availability projection of 19,039 canonical source records. It deliberately
  excludes numeric database IDs and mixed-unit magnitude values. Its 501 repeated
  projected rows do not define source-key duplication; canonical source/key
  duplicates remain zero. Source-inapplicable daily/UTC fields retain nulls.

Profile warnings support the manual quality audit and recorded curation decisions.
They do not cause record removal, imputation or a causal/severity interpretation.
Exact input/output hashes, settings and package versions are in
`workshop_3/evidence/eda_20261124/` and `requirements-workshop3-eda.txt`.

Use the separate Python 3.12 analysis environment; the tested Airflow dependency
contract is unchanged. On Windows, a short environment path avoids the long-path
installation issue encountered in this project directory:

```powershell
python -m venv "$env:TEMP/team9-eda-20261124"
& "$env:TEMP/team9-eda-20261124/Scripts/python.exe" -m pip install -r requirements-workshop3-eda.txt
& "$env:TEMP/team9-eda-20261124/Scripts/python.exe" scripts/workshop_3/execute_eda_notebooks.py --notebook notebooks/03_silver_quality_review.ipynb --receipt workshop_3/evidence/eda_20261124/quality_notebook_execution.json
```

Restore the exact reviewed Silver inputs first using `restore_silver.py` after
cloning. Dependency installation is separate from notebook execution. Select
this environment in the editor when running cells manually.
