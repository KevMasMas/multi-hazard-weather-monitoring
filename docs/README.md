# Documentation

- `plans/`: semester-level sequence only. Current assignments live in `WORK_BOARD.md`.
- `reports/`: evidence-backed reviews and progress summaries.
- `decisions/`: durable architecture and data-contract decisions.
- `references/`: concise indexes to authoritative external material.

Avoid duplicating professor-issued documents. Link to them, summarize only what is necessary for decisions, and state the date or commit reviewed.

Milestone-specific execution documents do not live here. Use `deliveries/<number>-<milestone>/` for the implementation plan, chronological change log, evidence register, review checklist, and any demo guide. Promote only still-current decisions and reusable guidance from a delivery into `docs/`.
