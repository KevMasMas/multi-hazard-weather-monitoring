# Decision Records

Create a numbered Markdown record for material, durable decisions, for example:

```text
0001-us-region-and-regional-unit.md
0002-scheduler-selection.md
0003-canonical-weather-domain-model.md
0004-compound-hazard-index.md
```

Each record should include status, date, context/evidence, decision, alternatives considered, consequences, and approvers. Do not mark a proposal as accepted until both team members agree.
